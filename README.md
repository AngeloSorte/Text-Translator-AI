# 📖 Text Translator AI

A simple Python project for translating text from **Italian to English** using Hugging Face's MarianMT pretrained models.

## 📦 Requirements

- Python 3.x  
- `transformers`  
- `sentencepiece`  
- `torch`  

To install the required libraries, run:

(bash)
pip install -r requirements.txt


🚀 How to Use

Run the script with:
python translator.py

Then input a sentence in Italian when prompted — the program will return the English translation instantly.
